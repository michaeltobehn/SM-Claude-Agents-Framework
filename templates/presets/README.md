# Presets – BMAD Lite

Vorkonfigurierte CLAUDE.md Templates für bekannte Projekt-Setups.

## Verwendung

Statt `/setup` von Grund auf zu nutzen, kann ein Preset als Startpunkt dienen:

1. Preset nach `./CLAUDE.md` kopieren
2. Projektspezifische Werte anpassen (Name, Domains, etc.)

## Verfügbare Presets

| Preset | Tech Stack | Beschreibung |
|--------|-----------|-------------|
| `supermatt.md` | Next.js + Supabase + Drizzle + Turborepo | SUPERMATT App Suite (Monorepo mit Auth, TRAX, Friday, Subz) |

## Eigenes Preset erstellen

Nach einem erfolgreichen `/setup` kann die generierte CLAUDE.md als neues Preset hier abgelegt werden.
